# Support

For ani-tui installation, layout, configuration, dependency-doctor, or frontend integration problems, open a structured issue:

<https://github.com/Killersumit/ani-tui/issues/new/choose>

For anime lookup, extraction, source-site, stream URL, or backend playback behavior that also occurs when using ani-cli directly, report it upstream:

<https://github.com/pystardust/ani-cli/issues>

Before reporting an ani-tui problem, include:

- `ani-tui --version`;
- the operating system, CPU architecture, terminal, and terminal dimensions;
- the ani-cli version/commit when known;
- exact reproduction steps;
- bounded diagnostics from the Activity view, with private paths/history removed.

Security vulnerabilities must be reported privately as described in [`SECURITY.md`](SECURITY.md).
